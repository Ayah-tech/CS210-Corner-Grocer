# CS210 – Corner Grocer

A C++ grocery item tracking program developed for CS-210 at Southern New Hampshire University.

## Project Overview

For Project Three, I developed a C++ program to help Corner Grocer track how frequently different grocery items were purchased. The program reads purchase records from a text file, counts item frequencies, and allows users to search for an item, display all item frequencies, or view a histogram. The goal was to make purchase data easier to understand and help the store identify customer buying patterns.

## What I Did Well

I think one of my strengths in this project was organizing the program around clear functions and a menu that users could navigate. I used a map to store item names and their frequencies, which helped organize the data and made it easier to retrieve the counts. I also focused on making the results readable so users could understand the information.

## Areas for Improvement

I could improve the program by adding stronger input validation and more detailed error handling. For example, I could make the program handle invalid menu choices and missing input files more gracefully. I would also like to add more testing for unusual situations. These changes would make the program more reliable and easier to maintain.

## Challenges and Resources

The most challenging part was working with file input and output while making sure the item frequencies were counted correctly. I worked through the challenges by reviewing course materials, examining the code carefully, and testing the program in Visual Studio. I learned that breaking a problem into smaller steps makes debugging easier. I plan to continue using course resources, official C++ documentation, and debugging tools as I develop my programming skills.

## Transferable Skills

This project helped me strengthen my understanding of C++, file handling, maps, functions, loops, and conditional statements. I also practiced debugging and problem-solving. These skills will be useful in future programming courses and software development projects, especially when working with data and creating programs that respond to user input.

## Maintainability, Readability, and Adaptability

I worked to keep the code readable by using meaningful names and organizing related operations into functions. The program's structure makes it easier to understand how data is loaded, processed, and displayed. Separating these responsibilities also makes future improvements, such as adding new reports or additional input checks, easier to implement.
